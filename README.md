# Petri Dish Tycoon

A free, browser-based microbiology strategy game. Grow a bacterial colony to one billion cells while you manage temperature, acid waste and food, and survive antibiotics, phages, mold and a faulty thermostat.

Open `index.html` in any modern browser. It works offline and makes no network requests.

To host it, upload this folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, itch.io, a school server). For GitHub Pages: upload the files to a repository, then Settings, Pages, deploy from the `main` branch root.
